# 本服务器存储策略

## 默认公共目录

每次会话开始时，先请用户确认后才可使用：

| 内容 | 默认路径 |
| --- | --- |
| 基础大模型、嵌入模型、重排模型和其他可复用模型权重 | `/publicdata/model` |
| 可复用数据集 | `/publicdata/data` |

两个目录均为多人共享且可编辑。同名条目并不代表内容相同，且不得自动修改公共目录中的内容。

## 重复内容验证标准

将个人文件判定为公共内容的重复副本前，应尽可能确认：

1. 内容用途与模型/数据集版本一致。
2. 目录类产物的相对文件清单一致。
3. 文件大小一致。
4. 对即将删除的文件，内容哈希一致。

任何冲突或证据不足均应标为“未知”或“冲突”，建议用户审查或使用新的带版本号目标目录，绝不覆盖公共文件。

## 复制与校验

用户确认某个可复用模型或数据集尚未共享时：

1. 与用户确定不冲突、带版本号的目标目录。
2. 复制时保留个人源副本。
3. 校验目标目录的文件清单和哈希。
4. 报告校验结果。
5. 单独询问是否删除个人源副本。

## 明确确认

删除个人内容、移除 Conda 环境、修改公共路径或执行批量操作前，必须重新取得用户对明确编号或路径的肯定确认。不得基于未经审查的通配符执行删除。


## V2：兼容旧代码的路径交接

个人模型或数据集已确认与公共副本等价时，删除个人副本前可保留原路径作为绝对符号链接，使旧代码继续访问该路径时实际读取公共内容。

只可在以下条件全部满足时使用：

1. 个人路径位于本次确认的个人目录内，且不是该个人目录本身。
2. 公共目标位于本次确认的公共根目录内。
3. 个人路径不是已有符号链接，个人与公共对象类型相同。
4. 已使用内容哈希验证两者相等，且没有活跃任务使用个人路径。
5. 用户已明确确认“建立链接”，不是仅确认“删除”。

`link_to_public.py --apply --verify` 会将个人源路径改名为同级、带时间戳的备份，再在原位置创建绝对符号链接并验证。它不删除备份。只有用户验证代码正常运行并再次点名确认备份路径后，才能删除备份。建立链接或链接验证失败时，应恢复备份，不可留下失效路径。
